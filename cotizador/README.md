# Cotizador comercial B2B TechPyme

Aplicación demostrativa para cotizar productos y servicios tecnológicos en pesos chilenos.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Alcance

- Catálogo de servicios demostrativo.
- Cantidades y descuentos por volumen.
- IVA configurable al 19%.
- Datos de empresa y vigencia.
- Resumen imprimible.
- Compartir la solicitud por WhatsApp.

Los precios son sintéticos y no representan una lista comercial oficial. Para producción, la fuente de precios debe trasladarse a una API o base de datos con control de acceso.
