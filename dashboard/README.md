# Dashboard comercial TechPyme

Dashboard demostrativo construido con React, Vite y ECharts. Presenta ventas sintéticas en pesos chilenos, distribuidas por región, categoría y canal.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Datos

El archivo `src/data.js` contiene datos sintéticos de referencia. No representa ventas reales. Para conectar datos reales, sustituya ese módulo por una API o una fuente autorizada y mantenga el mismo contrato de campos.

## Publicación

El workflow de GitHub Pages compila esta aplicación y copia `dist/` a la ruta pública `/dashboard/`.
