📧 Configuración del Formulario de Contacto

Tu página tiene un formulario funcional, pero por defecto no envía emails reales. Aquí te presento 4 opciones para configurarlo:

✅ OPCIÓN 1: Formspree (Recomendado para principiantes)

Formspree es un servicio gratuito que no requiere backend propio.

Paso 1: Ve a formspree.io y crea una cuenta
Paso 2: Crea un nuevo formulario (form)
Paso 3: Obtén tu ID de formulario. Será algo como: YOUR_FORM_ID
Paso 4: Abre script.js y busca el comentario sobre Formspree (línea ~70)
Paso 5: Reemplaza YOUR_FORM_ID por tu ID real y descomenta el código fetch
Paso 6: En el HTML del formulario, agrega un campo oculto: 
<input type="hidden" name="_next" value="https://tudominio.com/gracias.html">
✓ Ventajas: Gratuito, sin servidor necesario, fácil configuración, soporte 24/7

✅ OPCIÓN 2: EmailJS (Sin servidor, con cliente)

EmailJS permite enviar emails directamente desde el navegador.

Paso 1: Ve a emailjs.com
Paso 2: Crea una cuenta y conecta tu servicio de email (Gmail, Outlook, etc.)
Paso 3: Obtén tu Service ID, Template ID y Public Key
Paso 4: Agrega esto a tu index.html en el <head>: 
<script type="text/javascript" src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/index.min.js"></script>
Paso 5: En script.js, agrega: 
emailjs.init('TU_PUBLIC_KEY');

document.getElementById('formulario').addEventListener('submit', function(e) {
    e.preventDefault();
    
    const serviceID = 'service_XXXX';
    const templateID = 'template_XXXX';
    
    emailjs.sendForm(serviceID, templateID, this)
        .then(() => {
            alert('¡Email enviado exitosamente!');
            this.reset();
        })
        .catch((err) => {
            alert('Error al enviar email: ' + JSON.stringify(err));
        });
});
✓ Ventajas: Gratuito, confiable, muchas opciones de personalización

✅ OPCIÓN 3: Backend propio con Node.js + Express

Recomendado si quieres control total y máxima seguridad.

Paso 1: Crea un archivo server.js en tu carpeta: 
const express = require('express');
const nodemailer = require('nodemailer');
const cors = require('cors');
require('dotenv').config();

const app = express();

app.use(cors());
app.use(express.json());
app.use(express.static('.'));

// Configura tu transporte de email
const transporter = nodemailer.createTransport({
    service: 'gmail',
    auth: {
        user: process.env.EMAIL_USER,
        pass: process.env.EMAIL_PASS
    }
});

app.post('/api/contacto', async (req, res) => {
    try {
        const { nombre, email, empresa, tipo, mensaje } = req.body;
        
        // Validación
        if (!nombre || !email || !empresa || !tipo || !mensaje) {
            return res.status(400).json({ error: 'Todos los campos son obligatorios' });
        }
        
        // Email a ti
        const mailOptions = {
            from: process.env.EMAIL_USER,
            to: process.env.EMAIL_ADMIN,
            subject: `Nuevo contacto: ${empresa}`,
            html: `
                <h2>Nuevo mensaje de contacto</h2>
                <p><strong>Nombre:</strong> ${nombre}</p>
                <p><strong>Email:</strong> ${email}</p>
                <p><strong>Empresa:</strong> ${empresa}</p>
                <p><strong>Tipo:</strong> ${tipo}</p>
                <p><strong>Mensaje:</strong></p>
                <p>${mensaje}</p>
            `
        };
        
        await transporter.sendMail(mailOptions);
        
        // Email de confirmación al usuario
        const confirmationMail = {
            from: process.env.EMAIL_USER,
            to: email,
            subject: 'Hemos recibido tu mensaje - TechPyme',
            html: `
                <h2>¡Gracias por contactarnos!</h2>
                <p>Hola ${nombre},</p>
                <p>Hemos recibido tu mensaje y nos contactaremos contigo pronto.</p>
                <p>Saludos,<br>Equipo TechPyme</p>
            `
        };
        
        await transporter.sendMail(confirmationMail);
        
        res.json({ success: true, message: 'Email enviado correctamente' });
    } catch (error) {
        console.error('Error:', error);
        res.status(500).json({ error: 'Error al enviar email' });
    }
});

app.listen(3000, () => {
    console.log('Servidor escuchando en puerto 3000');
});
Paso 2: Crea un archivo .env: 
EMAIL_USER=tu-email@gmail.com
EMAIL_PASS=tu-contraseña-o-token
EMAIL_ADMIN=tu-email-admin@gmail.com
Paso 3: Instala dependencias: 
npm install express nodemailer cors dotenv
Paso 4: Ejecuta el servidor: 
node server.js
Paso 5: En script.js, reemplaza el fetch con: 
fetch('http://localhost:3000/api/contacto', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        nombre: form.querySelector('input[placeholder="Tu nombre"]').value,
        email: form.querySelector('input[placeholder="Tu email"]').value,
        empresa: form.querySelector('input[placeholder="Nombre de tu empresa"]').value,
        tipo: form.querySelector('select').value,
        mensaje: form.querySelector('textarea').value
    })
})
.then(response => response.json())
.then(data => {
    if (data.success) {
        alert('¡Mensaje enviado exitosamente!');
        form.reset();
    } else {
        alert('Error: ' + data.error);
    }
})
.catch(error => console.error('Error:', error));
⚠️ NOTA: Para Gmail, debes usar una contraseña de aplicación especial, no tu contraseña de cuenta
✓ Ventajas: Control total, máxima seguridad, sin límites de emails, datos guardados en BD

✅ OPCIÓN 4: Netlify Forms (Si despliegas en Netlify)

Si alojaste tu sitio en Netlify, puedes usar su servicio de formularios.

Paso 1: En tu formulario HTML, agrega netlify: 
<form class="contacto-form" netlify>
Paso 2: En tu panel de Netlify, ve a Forms y configura notificaciones por email
Paso 3: ¡Listo! Netlify capturará automáticamente los envíos
✓ Ventajas: Super simple, no requiere código backend, integrado con Netlify

🔒 Checklist de seguridad

  • ✓ Valida SIEMPRE en el servidor (no solo cliente)
  • ✓ Sanitiza todas las entradas del usuario
  • ✓ Usa HTTPS en producción (obligatorio)
  • ✓ No guardes contraseñas en el código
  • ✓ Usa variables de entorno (.env)
  • ✓ Implementa rate limiting para prevenir spam
  • ✓ Usa CAPTCHA si recibas mucho spam

📧 Agregar CAPTCHA (Google reCAPTCHA)

Para evitar spam, agrega reCAPTCHA:

Paso 1: Ve a Google reCAPTCHA
Paso 2: Registra tu sitio y obtén las claves
Paso 3: Agrega esto a tu formulario HTML: 
<script src="https://www.google.com/recaptcha/api.js"></script>
<div class="g-recaptcha" data-sitekey="TU_SITE_KEY"></div>
Paso 4: En tu backend, valida el token: 
const verifyUrl = `https://www.google.com/recaptcha/api/siteverify?secret=${process.env.RECAPTCHA_SECRET}&response=${recaptchaToken}`;
const response = await fetch(verifyUrl, { method: 'POST' });
const data = await response.json();

if (!data.success || data.score < 0.5) {
    return res.status(400).json({ error: 'CAPTCHA inválido' });
}

❓ Preguntas frecuentes

¿Dónde guardo la información de los contactos?

Con Formspree o Netlify Forms, puedes verla en sus dashboards. Con tu propio backend, puedes guardarla en una base de datos (MongoDB, PostgreSQL, etc.)

¿Cuál es la más segura?

Tu propio backend es la más segura, pero también la más compleja. Para la mayoría de PYMEs, Formspree o EmailJS son suficientes y seguras.

¿Puedo cambiar de opción después?

Sí, solo necesitas cambiar el código JavaScript. Todas son independientes.
